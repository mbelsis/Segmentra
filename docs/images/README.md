# Screenshots Directory

This directory contains screenshots for the README.md documentation.

## Required Images

Please add the following screenshot files to this directory:

- `dashboard.png` - Dashboard page showing deployment metrics and charts
- `audit-log.png` - Audit log page showing deployment audit records
- `deployments.png` - Deployments list page
- `deployment-details.png` - Individual deployment details page
- `policy-sets.png` - Policy sets page
- `policy-version.png` - Policy version detail page
- `administration.png` - Administration settings page

## Image Guidelines

- Recommended format: PNG
- Recommended size: 1200-1600px width
- Keep file sizes reasonable (< 500KB per image)
- Use descriptive filenames as listed above
